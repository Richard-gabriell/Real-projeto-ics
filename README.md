# PALETA DE CORES OFICIAL — BLACK & ELECTRIC BLUE

**Identidade visual compartilhada:** Black & Electric Blue

## 1. Apresentação

A paleta Black & Electric Blue foi escolhida como padrão visual compartilhado entre os integrantes do grupo.

A combinação utiliza tons de preto e azul para transmitir tecnologia, modernidade, sofisticação e inovação.

Este documento estabelece as cores oficiais e orienta sua utilização para manter a consistência visual dos projetos desenvolvidos pelo grupo.

## 2. Cores oficiais

| Cor | Código HEX | Finalidade |
|---|---|---|
| Preto profundo | `#05070D` | Fundo principal |
| Azul escuro | `#111827` | Fundos secundários e painéis |
| Azul elétrico | `#005BFF` | Destaques e elementos principais |
| Azul brilhante | `#00A8FF` | Efeitos luminosos e detalhes |
| Branco gelo | `#EAF4FF` | Textos e ícones |

## 3. Como utilizar cada cor

### Preto profundo — #05070D
Cor predominante da interface.

- Fundo principal.
- Fundo das páginas.
- Áreas de trabalho.

### Azul escuro — #111827
Cor utilizada para criar profundidade e separar elementos.

- Cards.
- Painéis.
- Menus.
- Caixas de informações.

### Azul elétrico — #005BFF
Cor principal de destaque.

- Botões.
- Elementos selecionados.
- Indicadores de interação.
- Destaques importantes.

### Azul brilhante — #00A8FF
Cor responsável pelos detalhes tecnológicos.

- Efeitos luminosos.
- Bordas brilhantes.
- Animações.
- Elementos visuais.

### Branco gelo — #EAF4FF
Cor responsável pela legibilidade.

- Títulos.
- Textos.
- Ícones.
- Informações importantes.

## 4. Variáveis CSS oficiais

Para facilitar a utilização das cores, recomenda-se criar as seguintes variáveis:

```css
:root {
    --color-background: #05070D;
    --color-surface: #111827;
    --color-primary: #005BFF;
    --color-secondary: #00A8FF;
    --color-text: #EAF4FF;
}
```

### Exemplo de aplicação

```css
body {
    background: var(--color-background);
    color: var(--color-text);
}

.card {
    background: var(--color-surface);
}

button {
    background: var(--color-primary);
    color: var(--color-text);
}

.highlight {
    color: var(--color-secondary);
}
```

## 5. Regras de utilização

1. Manter o preto como cor predominante.
2. Utilizar o azul escuro para superfícies secundárias.
3. Reservar o azul elétrico para destaques e interações.
4. Utilizar o azul brilhante em efeitos e elementos visuais.
5. Utilizar o branco gelo para textos e ícones.
6. Evitar cores aleatórias que descaracterizem a paleta.
7. Evitar excesso de brilho e efeitos luminosos.
